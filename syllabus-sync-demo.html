Set up Google Calendar sync

This only works when you download this file and open it in a real browser — served from a real http:// or https:// address (e.g. run python3 -m http.server in the folder and open http://localhost:8000/syllabus-sync-demo.html). Google blocks its sign-in script inside Claude's in-chat preview, and double-clicking the file to open it as file:// won't work either — Google OAuth requires a registered http/https origin.

  1. In the Google Cloud Console, create an OAuth 2.0 Client ID (type: Web application). No client secret is needed for this flow.
  2. Under Authorized JavaScript origins, add the exact origin you're opening this file from (e.g. http://localhost:8000).
  3. Enable the Google Calendar API for that project.
  4. Paste the Client ID below, then click "Sync to Google Calendar" above — it'll prompt you to sign in and grant calendar access.
